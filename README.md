# Andy's Virtual EFF Dice-Generated Passphrases

This program is a knock-off of: [Diceware Password Generator](https://diceware.dmuth.org/)

## The problem
Easily crackable passwords from a computers standpoint.

[EFF Dice-Generated Passphrases](https://www.eff.org/dice)
[Diceware Password Generator](https://diceware.dmuth.org/)
[xkcd - Password Strength](https://xkcd.com/936/)

## Intended Audience
Anyone who uses passwords/passphrases.

## What the tool does
The EFF has come up with a novel way to produce a secure passphrase.  It requires the roll of 5 dice, 6 times and a lookup in a word list. The result is 6 easy to spell and remember words that will inspire your passphrase.

My tool uses python to virtualize the dice and automates the word list reference.
